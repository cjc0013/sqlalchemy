# PR 13461 — escape backslashes in mysql enum/set value rendering

**Queue:** Needs design or branch decision  
**Review unit:** `PR-13461`  
**Status:** Local technical option; not an upstream acceptance or merge claim.

## Problem and intended behavior

Description MySQLTypeCompiler._visit_enumerated_values renders ENUM and SET values by doubling single quotes but leaves backslashes untouched, so under the default sql_mode where a backslash is an escape character a value containing one is emitted wrongly, and a value ending in a backslash escapes the closing quote...
