# PR 13452 — mssql: exclude LOB types from length assignment in column reflection

**Queue:** Ready for technical review  
**Review unit:** `PR-13452`  
**Status:** Local technical option; not an upstream acceptance or merge claim.

## Problem and intended behavior

Summary MSSQL reflection of TEXT, NTEXT, and IMAGE columns picked up a bogus length from sys.columns.max_length. That value (16 bytes) is the size of the in-row LOB pointer, not an actual character or byte length. The reflected types came back as TEXT(length=16) and NTEXT(length=8), which broke a reflect-then-create...
