## Problem and intended behavior

MSSQL reflection of TEXT, NTEXT, and IMAGE columns picked up a bogus length from sys.columns.max_length. That value (16 bytes) is the size of the in-row LOB pointer, not an actual character or byte length. The reflected types came back as TEXT(length=16) and NTEXT(length=8), which broke a reflect-then-create.
