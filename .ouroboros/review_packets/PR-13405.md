## Problem and intended behavior

Add `orm/_loading_cy.py` with `_InstancesBatch`, a whole-chunk row processor built by `_instance_processor()` for the non-refresh, non-polymorphic load path. It replaces the per-row `[proc(row) for row in fetch]` comprehension in `instances()`, hoisting all per-query-constant conditions out of the row loop: - identity-map lookups go against `WeakInstanceDict._dict` directly; - `InstanceState` construction is inlined for the default `ClassManager` / `InstanceState` combination; - for tuple rows, the primary key and quick column populators are applied by position, with itemgetter indexes recovered by probing the getters against a `range` object. Rows for instances already in the identity map delegate to `_instance()`, which keeps the partial-population, populate_existing and version-check paths. Runs as plain Python when the extension is not compiled.
